Add reader mode: a fully rendered, read-only view of the current page — real heading sizes, tables, horizontal rules, and syntax-highlighted code blocks — toggled with `Cmd/Ctrl+Shift+V`, the title-bar preview/edit icons, or a double-click to return to editing.
